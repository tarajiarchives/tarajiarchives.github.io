    Partager une archive.

    Une vieille photo dans l'album de famille ? Un billet de match, une coupure de presse, une vidéo ? Envoyez-la pour qu'elle reste dans la mémoire de l'Espérance.

    • Une courte description est obligatoire : quoi, où, quand, qui est sur la photo.
    • Vidéo : un lien YouTube ou un fichier court.
    • N'envoyez que ce que vous avez le droit de partager (photos de famille, vos photos, vos archives).
    • Les archives retenues sont publiées dans « Archives des supporters », avec votre nom ou anonymement, comme vous le choisissez.
