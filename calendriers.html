    Calendriers & Records.

    Tous les matchs officiels des clubs tunisiens — Ligue 1, Coupe de Tunisie, compétitions africaines — sur la période de votre choix : qui a le plus joué, avec combien de jours de repos, les périodes les plus chargées et les records. Chaque chiffre se clique pour voir les matchs qui le composent.

    Sources et limites

    Ligue 1 : tous les matchs datés depuis 1999. Coupe de Tunisie : Wikipédia (fr) et RSSSF. Compétitions africaines : RSSSF (dates des tours telles qu'il les publie) et Wikipédia. Aucune date n'est inventée : un match sans date compte dans le total, mais pas dans les jours de repos ni les périodes ; un record calculé sur une période contenant des matchs non datés est affiché « provisoire ». Les matchs gagnés sur tapis vert sans être joués ne comptent pas.
